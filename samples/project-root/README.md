# Sample project-root scaffold

Point `--project-root` at a **BIM job folder**, not necessarily the NavisMcp git clone.

This directory shows the expected empty layout:

- `exports/` — NWD exports
- `snapshots/` — native viewport PNGs
- `reports/` — clash/QA/issue packs
- `models/` — optional append-model inputs

Copy these empty folders into your real project, or let the server create them on first write.
