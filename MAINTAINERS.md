# Maintainers

## Project

| Role | Contact |
|------|---------|
| Security reports | [GitHub Security Advisories](https://github.com/navis-mcp/navis-mcp/security/advisories/new) |
| General issues | [GitHub Issues](https://github.com/navis-mcp/navis-mcp/issues) |
| Package / Autodesk listing contact | `security@navis-mcp.dev` |

NavisMcp is maintained by the repository owners on GitHub (`navis-mcp/navis-mcp`). Until the GitHub organization is created and ownership transferred, treat this file as the canonical contact map and update names/handles when the org is live.

## Responsibilities

- Triage security advisories within a reasonable time
- Keep `docs/capability-matrix.md` honest (Supported / Partial / Stub)
- Gate releases so the zip always includes a built plug-in DLL
- Do not merge personal BIM job paths, NWF filenames, or client clash scripts into the product tree

## Becoming a maintainer

Open an issue proposing maintainership after sustained, high-quality contributions (code, docs, or security review).
